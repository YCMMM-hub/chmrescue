Open a CHM file in a browser

A .chm file is a bundle of HTML pages, images and an index, compressed by Microsoft. A browser cannot open it directly, but a reader written in JavaScript can unpack it on the spot.

Open it in your browser

Drop the file into CHMRescue: contents, search and images work offline, and the file is never uploaded. Reading is free.

Open a CHM file

Steps

  1. Open CHMRescue.
  2. Drop your .chm file (or click to choose it).
  3. Use the contents on the left, or search; pages appear on the right.

Want the content as ordinary files?

The paid Export Pass turns a manual into a ZIP of HTML, Markdown and plain text, or one document you can print to PDF.

Limits, honestly: encrypted CHM files do not open, and some Free Pascal manuals (duplicate directory entries) are refused with a clear message. Search is a plain-text search of the pages. Old scripts inside CHM pages do not run — on purpose, for your safety.
