How to open a CHM file on a Mac

macOS cannot open Microsoft .chm help files by default, and double-clicking one does nothing useful. You do not need to install a desktop app: a modern browser is enough.

  1. Open CHMRescue in Chrome.
  2. Drag the .chm file onto the drop area.
  3. Browse the contents or search; use Export if you need the manual as HTML, Markdown, text or one printable document.

Open it in your browser

Drop the file into CHMRescue: contents, search and images work offline, and the file is never uploaded. Reading is free.

Open a CHM file

If the file seems blank only on a Windows PC, that is a different problem: see CHM file not showing content.

Limits, honestly: encrypted CHM files do not open, and some Free Pascal manuals (duplicate directory entries) are refused with a clear message. Search is a plain-text search of the pages. Old scripts inside CHM pages do not run — on purpose, for your safety.

Questions

Why does my Mac not open CHM files?

CHM is a Microsoft format (Compiled HTML Help). macOS ships no viewer for it.

Is it free?

Reading is free. Exporting (ZIP, one printable document, several files at once) is a one-time paid pass.
