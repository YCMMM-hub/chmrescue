Why?

.chm files (Microsoft Compiled HTML Help) are often blocked or blank on Windows, and do not open on Mac, Chromebook or Linux. CHMRescue reads them right in Chrome.

On Windows, if the content does not show: right-click the file → Properties → tick “Unblock” → OK, then open it again. That is free and works without CHMRescue.

Questions

Are my files uploaded anywhere?

No. The file is read inside your browser, on your computer. The extension makes no network request and asks for no browser permission.

How does “PDF” work?

With the Export Pass, CHMRescue assembles the manual’s pages into one document; you then print it with Chrome’s print dialog and choose “Save as PDF”. It is not a one-click PDF, and the original page styling is simplified (text, images, tables and code are kept). Very large manuals are split into parts of 400 pages.

Does it open every CHM?

No. Encrypted files do not open, nor some Free Pascal manuals (duplicate directory entries). A clear message is shown in that case.

I bought the Pass on the website — does it work here?

Yes: click “I already have a code” and enter the activation code shown after payment. The extension has its own storage, so the code is entered once here.
