A CHM viewer for Chrome

Chrome does not open .chm files. CHMRescue adds a viewer that runs inside Chrome — as a web page, or as an extension that asks for no permission at all.

Open it in your browser

Drop the file into CHMRescue: contents, search and images work offline, and the file is never uploaded. Reading is free.

How it is safe

  • The extension requests no browser permission and makes no network request.
  • Pages from the manual are shown in a locked-down frame: no scripts run, no request is made while you read a manual, links to outside sites are disabled.
  • Nothing is stored except, if you buy the pass, a flag saying your code was accepted.

Limits, honestly: encrypted CHM files do not open, and some Free Pascal manuals (duplicate directory entries) are refused with a clear message. Search is a plain-text search of the pages. Old scripts inside CHM pages do not run — on purpose, for your safety.
