CHM file not showing content: the fix

You open a .chm help file and see the table of contents but the right-hand page is blank, or an error such as “Navigation to the webpage was canceled”. This is very often Windows blocking a file that was downloaded from the internet.

The free Windows fix (no tool needed)

  1. Close the help file. Right-click the .chm file → Properties.
  2. On the General tab, at the bottom, tick Unblock (next to “This file came from another computer and might be blocked”).
  3. Click Apply, then OK, and open the file again. If the box is missing, the file is not blocked: try copying it to a local folder (CHM files often fail from network drives or very long paths).

If you are on a Mac, Chromebook or Linux — or the fix does not help — use CHMRescue below.

Why it happens

Windows marks files downloaded from the internet or received by e-mail as coming from another computer. The old HTML Help viewer then refuses to display the pages inside, even though the file itself is fine.

If you cannot use Windows’ viewer

On a Mac, Chromebook or Linux there is no built-in CHM viewer at all.

Open it in your browser

Drop the file into CHMRescue: contents, search and images work offline, and the file is never uploaded. Reading is free.

Open a CHM file

Limits, honestly: encrypted CHM files do not open, and some Free Pascal manuals (duplicate directory entries) are refused with a clear message. Search is a plain-text search of the pages. Old scripts inside CHM pages do not run — on purpose, for your safety.

Questions

Is the file damaged?

Usually not. If the contents list appears but the pages are blank, the file is typically just blocked. If nothing opens at all, the file may be damaged or encrypted.

Do I have to install anything?

No. CHMRescue runs in the browser; the Windows fix above needs nothing at all.
